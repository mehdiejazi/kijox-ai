# راهنمای نصب افزونه `Kijox AI` از فایل VSIX

اگر فایل `kijox-ai.vsix` را در اختیار دارید، می‌توانید افزونه را به‌صورت آفلاین در VS Code نصب کنید.

## مراحل نصب

1. وارد بخش `Extensions` شوید.
   میانبر: `Ctrl+Shift+X`

2. از بالای پنل Extensions روی منوی `...` (سه نقطه) کلیک کنید.

3. گزینه `Install from VSIX...` را انتخاب کنید.

4. فایل `kijox-ai.vsix` را انتخاب کنید.

5. بعد از نصب، وارد تنظیمات VS Code شوید.
   میانبر: `Ctrl+,`

6. در جستجوی تنظیمات عبارت `Kijox AI` را وارد کنید.

7. مقدار `Base URL` را تنظیم کنید.
   مثال:

```text
https://api.avalai.ir/v1
```

8. گزینه `enableCustomModels` را روی `true` قرار دهید.

## نکته

بعد از ساخته‌شدن فایل `kijox-ai.vsix` می‌توانید آن را به هر سیستم دیگری منتقل کنید و از همان مسیر `Install from VSIX...` نصبش کنید.
